Using Marp Importer

Marp Importer turns a Marp markdown deck into native Canva pages. Paste your Marp markdown and select Build slides — each slide becomes a Canva page. Headings, body text, bulleted lists, and tables come across as editable Canva elements.

A few things to expect, by design:

  • Add images directly in Canva — they aren't imported.
  • Speaker notes are not transferred.
  • Mermaid diagrams arrive as code, which you can convert using a Mermaid app from the Canva marketplace.
