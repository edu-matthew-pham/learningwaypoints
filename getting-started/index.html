Getting started

Eight tools,
one philosophy.

Learning Waypoints is a free suite of curriculum tools for Australian educators. Every tool works on its own, so you can pick whichever solves the problem in front of you. The one underlying idea they share is that classes should stay on one dependency-ordered path, with width, not acceleration, as the lever when pace differs. The more tools you use, the more they complement each other.

Start with any tool · No account required · Free to use
Start in minutes

These two work with nothing but what you bring. Need to see the shape of a topic — for your own planning or to explore with students? Start with Topic Explorer. Need a deck or a worksheet for a specific lesson? Start with Prepare.

✦Topic Explorer

Type any topic and Topic Explorer builds you a prompt. Paste it into whatever AI you already use, paste the result back, and you have a structured topic map — clusters, nodes, quizzes, matching activities. Use it for your own planning first: five minutes and you can see the conceptual terrain before you've written a lesson. Then take the same map into class — project it, explore it together, or generate a coaching prompt that lets students work through it with an AI that stays within the boundaries you set.

Type a topic you're teaching next term, even one you haven't taught before. Ten minutes, start to finish.

▦Waypoints Prepare

When you know what you're teaching and need the material for it. Prepare has two sides.

Present: describe your lesson and Prepare writes you a prompt that generates the deck. Paste the result back and edit it with the slides showing beside you as you type. Send a deck to someone as a link, or export it to PowerPoint if you'd rather present from there.

Print: the same text, laid out as a worksheet instead, with lines for students to write on, boxes, blanks to fill in, and notes that appear on your copy but not theirs. You can mark part of a sheet as extra, so a class that's ready for more gets it from the same worksheet as everyone else. Print it, or copy it into Google Docs, Word, OneNote, Schoolbox, or anywhere else that takes formatted text.

Either side, you can work on a whole set at once rather than one file at a time: add each deck or worksheet as you finish it, regenerate and replace any of them, then download the set together.

Load the sample to see how it feels, then try the Generate tab with a lesson of your own.

One pattern, everywhere

The tool builds a prompt → You paste it into your AI → You paste the result back

Every generating tool in the suite works the same way, and it's a deliberate choice, not a limitation. Your content never touches our servers — there are no accounts, nothing is stored, and you use whichever AI your school already trusts. The tools' job is to build you a much better prompt than you'd write by hand: one that knows the curriculum, the structure, and the format the tool expects back.

Once you've done it in one tool, you've done it in all of them.

The idea behind it

The thing that connects every tool is a shared idea: a waypoint, one step on the dependency-ordered path through a topic. The Planner sequences waypoints for a unit. Prepare builds the slides and handouts for them. Signal checks confidence on them. Insight classifies thinking against them. Audio narrates them. Because every tool speaks the same language, work you do in one carries into the others.
